# 插件 ID 分配记录

本文件记录所有新闻源插件的 ID 分配情况。

## ID 分配规则

| ID 范围 | 用途 | 说明 |
|--------|------|------|
| 1-99 | 系统保留 | 内置官方插件 |
| 100-999 | 官方扩展 | 官方维护的第三方源 |
| 1000+ | 用户插件 | 用户自定义插件 |

## 如何申请新 ID

1. 在此文件中选择一个未使用的 ID
2. 在表格中添加一行，标记为 🚧 开发中
3. 开发完成后更新为 ✅ 已启用
4. 提交 PR 或更新此文件

## 注意事项

- ID 一旦分配，**不可更改**（否则会影响已有用户的配置）
- 删除插件时，ID 可以**回收重用**
- 自定义插件建议使用 1000+ 的 ID，避免与官方插件冲突
