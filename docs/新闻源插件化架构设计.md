## 一、背景与目标

### 1.1 现状问题
- 新闻源硬编码在主程序中，新增/修改需改动核心代码
- 各新闻源接口不统一，维护困难
- 无法动态启用/禁用新闻源

### 1.2 重构目标
- 插件化架构：每个新闻源独立成插件
- 唯一标识：数字 ID 系统，便于 API 调用
- 标准化接口：获取新闻、播放新闻分离
- 易扩展：新新闻源快速接入
- 可管理：UI 界面管理插件

## 三、接口规范

### 3.1 插件接口定义

每个新闻源插件必须实现以下方法：

| 方法 | 说明 | 返回值 |
|-----|------|-------|
| `info` | 插件元信息 | `PluginInfo` |
| `fetch_news()` | 获取新闻列表 | `Dict{items, has_more, next_cursor}` |
| `get_news_detail()` | 获取新闻详情 | `NewsItem` 或 `None` |
| `play_news()` | 播放新闻（语音） | `bool` |
| `search_news()` | 搜索新闻 | `List[NewsItem]` |
| `health_check()` | 健康检查 | `bool` |

### 3.2 API 接口

| 接口 | 方法 | 说明 |
|-----|------|------|
| `/api/v1/plugins` | GET | 获取所有新闻源 |
| `/api/v1/plugins/{id}/news` | GET | 获取新闻列表 |
| `/api/v1/plugins/{id}/news/{news_id}` | GET | 获取新闻详情 |
| `/api/v1/plugins/{id}/news/{news_id}/play` | POST | 播放新闻 |
| `/api/v1/plugins/{id}/search` | GET | 搜索新闻 |
| `/api/v1/plugins/{id}/status` | PUT | 启用/禁用 |
| `/api/v1/plugins/{id}/config` | GET/PUT | 配置管理 |

## 六、新增功能 (2026-05-02)

### 生命周期钩子
插件支持 `on_load()` 和 `on_unload()` 生命周期方法：

```python
class MyPlugin(INewsSource):
    def on_load(self):
        # 插件加载时初始化
        pass

    def on_unload(self):
        # 插件卸载时清理
        pass
```

### 版本兼容性检查
使用语义化版本 (SemVer) 检查插件与主程序的兼容性：

```python
# 支持的格式
"*"           # 兼容所有版本
""            # 兼容所有版本
"1.0.0"      # 精确匹配
">=1.0.0"    # 大于等于
">=1.0.0,<2.0.0"  # 版本范围
```

### Meta 验证
`cwplugin.json` 必填字段：
- `id` - 插件唯一 ID
- `name` - 插件名称
- `version` - 版本号
- `api_version` - 要求的 API 版本
- `author` - 作者

## 六、维护指南

### 新增新闻源步骤

1. 分配 ID（在 `docs/PLUGIN_IDS.md` 登记）
2. 创建 `plugins/{plugin_name}/` 目录
3. 实现 `INewsSource` 接口
4. 添加 `cwplugin.json` 元数据文件
5. 测试验证

### 常见问题

**Q: 插件加载失败？**  
检查：类是否导出 `plugin_class`、ID 是否冲突、JSON 是否合法

**Q: 如何调试？**  
在 `plugin_manager.py` 设置日志级别为 DEBUG

**Q: 插件不兼容怎么办？**  
UI 会显示"不兼容"标签，但插件仍可加载使用
